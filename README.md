# Buck's Lawn Care website

Single-page static website for Buck's Lawn Care (Ryan Buchman), a lawn care business in St. Petersburg, FL.

Live: https://rudsrudibotha.github.io/bucks-lawn-care-preview/

## Files
- `index.html`: the page (services, our story, awards, neighbor review, free estimate contact details)
- `styles.css`: all styles, including the mobile menu and quick-contact bar
- `images/`: logo, favicon, social sharing image and photos
- `SOURCES.txt`: image credits
- `.nojekyll`: serves the files as-is on GitHub Pages

No build step. Open `index.html` in a browser, or serve the folder with any static web server.
